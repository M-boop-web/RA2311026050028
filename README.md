# DSL Compiler — Full Pipeline in C + Flask UI

A complete end-to-end compiler for a custom Domain-Specific Language (DSL),
featuring Flex lexing, Bison parsing, AST construction, C code generation,
GCC compilation, and a Flask-based web IDE.

---

## Project Structure

```
dsl_compiler/
├── compiler/
│   ├── lexer.l          # Flex lexer specification
│   ├── parser.y         # Bison grammar + AST actions
│   ├── ast.h / ast.c    # AST node types, constructors, printer, cleanup
│   ├── codegen.h / .c   # C code generator (walks AST, emits C)
│   ├── main.c           # Compiler driver (semantic check + orchestration)
│   │
│   │── lexer_manual.c   # Hand-written tokenizer (fallback when flex absent)
│   ├── parser_manual.c  # Recursive-descent parser (fallback when bison absent)
│   ├── parser.tab.h     # Token enum header (normally generated by bison -d)
│   │
│   ├── Makefile         # Build system
│   └── sample.dsl       # Demo DSL program
│
└── web/
    ├── app.py           # Flask application
    └── templates/
        └── index.html   # Web IDE (editor + pipeline visualizer + output)
```

## DSL Language Reference

### Variable Declaration
```dsl
let <name> <type> = <expr>;
```
Types: `int`, `float`, `string`

### Assignment
```dsl
<name> = <expr>;
```

### Print
```dsl
print(<expr>, <expr>, ...);
```

### Arithmetic
Supports `+`, `-`, `*`, `/`, parentheses, and operator precedence.

### Comments
```dsl
// This is a line comment
```

## Compilation Pipeline

```
DSL source
    │
    ▼
[LEXER]    flex / lexer_manual.c
    │      Tokenises: keywords, identifiers, literals, operators
    ▼
[PARSER]   bison / parser_manual.c
    │      Recursive-descent, builds token stream into grammar rules
    ▼
[AST]      ast.c / ast.h
    │      Tree of typed nodes: Program → Stmt* → Expr*
    ▼
[SEMANTIC] main.c
    │      Type inference, warning on string arithmetic, symbol table
    ▼
[CODEGEN]  codegen.c
    │      Walks AST, emits equivalent ANSI C with printf format selection
    ▼
[GCC]      system gcc
    │      Compiles generated out.c → native binary
    ▼
[EXEC]     binary output
```

## Build & Run

### Option A — with Flex + Bison installed
```bash
cd compiler
make
make run SRC=sample.dsl
```

### Option B — without Flex/Bison (manual fallback, already compiled)
```bash
cd compiler
gcc -Wall -g main.c ast.c codegen.c lexer_manual.c parser_manual.c -o dslc
./dslc sample.dsl -o out.c -ast
gcc -o out out.c && ./out
```

## Flask Web Interface

```bash
cd web
pip install flask
python app.py
# → http://localhost:5000
```

Features:
- Syntax-aware code editor with tab indentation
- Real-time pipeline visualiser (LEXER → PARSER → AST → CODEGEN → GCC → EXEC)
- AST tree viewer with colour-coded node types
- Generated C viewer with syntax highlighting
- Program output terminal

## Example DSL Program

```dsl
let x int = 10;
let y int = 20;
let pi float = 3.14159;
let msg string = "Hello, World!";

let sum int = x + y;
let product int = x * y;

print(msg);
print(sum);
print(product);
print(x, y, sum);
```

Generated C output:
```c
#include <stdio.h>
int main(void) {
    int x = 10;
    int y = 20;
    float pi = 3.141590f;
    char* msg = "Hello, World!";
    int sum = (x + y);
    int product = (x * y);
    printf("%s\n", msg);
    printf("%d\n", sum);
    printf("%d\n", product);
    printf("%d %d %d\n", x, y, sum);
    return 0;
}
```

Program output:
```
Hello, World!
30
200
10 20 30
```
